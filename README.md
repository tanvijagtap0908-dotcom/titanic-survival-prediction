# Titanic Survival Prediction Using Machine Learning

## Project Overview
This project predicts passenger survival on the Titanic using machine learning classification algorithms. It covers data preprocessing, exploratory data analysis, model training, evaluation, and an interactive prediction interface using Gradio.

## Objectives
- Analyze Titanic passenger data.
- Clean and preprocess data.
- Perform exploratory data analysis (EDA).
- Train classification models.
- Evaluate model performance.
- Build an interactive prediction interface.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Gradio
- Google Colab

## Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## Project Workflow
1. Load and inspect the dataset.
2. Handle missing values.
3. Encode categorical features.
4. Visualize passenger survival patterns.
5. Split the data into training and testing sets.
6. Train and evaluate the models.
7. Generate predictions using the trained model.

## Dataset
The project uses Titanic passenger data. The dataset must be available as `Titanic.csv` when running the notebook in Google Colab.

Dataset source: [Kaggle Titanic Competition](https://www.kaggle.com/competitions/titanic/data)

## How to Run
1. Open the notebook in Google Colab.
2. Upload `Titanic.csv` to the Colab session.
3. Install the required Python libraries if needed.
4. Run the notebook cells in order.
5. Launch the Gradio interface to test predictions.
